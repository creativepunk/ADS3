# Text Area

A multi-line text input for free-form content. Use `ds-text-area` when users need to enter longer text that may span multiple lines — descriptions, notes, messages, or comments. For single-line inputs use `ds-text-field` instead.

<Canvas of={TextAreaStories.Default} />

## States

The text area supports the same validation and interaction states as `ds-text-field`: default, hover, focus, invalid, valid, disabled, and read-only. The textarea body grows vertically with its content (min-height 56px, max-height 192px) and scrolls internally once it reaches the maximum height.

## Grow behaviour

The textarea hugs all content until the actual text element. The text element has a minimum height of 56px and a maximum height of 192px — after which it scrolls internally. All content above and below (label, footer) hugs to fit.

## Inline layout

`type="inline"` places the label in a fixed 180px column to the left, matching the layout convention used in `ds-text-field`.

## Accessibility

- The native `<textarea>` element is used directly — full keyboard, screen reader, and form participation is native.
- `aria-label` is applied from the `label` prop when a label is present; falls back to `"Text area"` for cases without a visible label.
- `aria-invalid="true"` is applied when `invalid` is set, allowing screen readers to announce the error state.
- `aria-multiline="true"` is explicit on the element.
- Focus ring uses `--ds-focus-focus` via `:focus-within` on the trigger wrapper — consistent with `ds-text-field`.
- Disabled state sets `pointer-events: none` and uses explicit disabled tokens on the textarea and label text — never `opacity`.

## React usage

```tsx
import { DsTextArea } from '@my-ds/react';
import type { DsInputEvent, DsChangeEvent } from '@my-ds/components';

function CommentForm() {
  const [value, setValue] = React.useState('');

  return (
    <DsTextArea
      label="Comment"
      isRequired
      placeholder="Write your comment..."
      value={value}
      helperText="Be respectful."
      maxlength={500}
      hasCount
      onDsInput={(e: DsInputEvent) => setValue(e.detail.value)}
      onDsChange={(e: DsChangeEvent) => console.log('committed:', e.detail.value)}
      style={{ width: '100%' }}
    />
  );
}
```
